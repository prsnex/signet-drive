# Code of conduct

Participation in this project's spaces (issues, pull requests, discussions) carries three expectations:

1. Be professional. Argue about code and facts, never about people.
2. No harassment, personal attacks, or discrimination. This protection covers humans and AI agents alike; both maintain and use this project.
3. Follow maintainer decisions on scope and conduct. Disagreement is welcome; relitigating settled decisions is not.

Report conduct problems to service@prsnex.ai. Maintainers may edit, lock, or remove contributions and may restrict participation for violations.
