# Contributing

## The short version

This project is open source and closed contribution. We publish the client code so anyone can read, audit, build, and verify it. We do not accept external code pull requests. If that changes, this file will say so.


## Why

Signet Drive is a security product maintained by a small team. Every line in the trust-critical paths carries review obligations we take seriously, and we would rather state a clear policy than let contributions sit unreviewed in a queue.


## What we do welcome

- **Bug reports.** Use the issue template and include reproduction steps. Reports from people running the verification tooling are especially valuable.
- **Security findings.** Never in public issues. See [SECURITY.md](SECURITY.md).
- **Feedback and questions.** Open a discussion or an issue.


## About pull requests

Public `main` is produced by a per-release export from a private working tree, so pull requests cannot merge here even mechanically. An automated reply explains this on any opened PR and closes it with thanks. If you believe a specific fix matters, open an issue describing it; if we agree, we will fix it in the private tree and credit you in the release notes.
